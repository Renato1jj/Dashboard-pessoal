
# Dashboard Pessoal

Um dashboard pessoal desenvolvido para organizar tarefas,
acompanhar metas e registrar anotações diárias.

## Funcionalidades

- [x] Relógio e data em tempo real
- [x] Adicionar tarefas
- [x] Concluir tarefas
- [x] Excluir tarefas
- [x] Contador de tarefas
- [x] Salvar tarefas no LocalStorage
- [x] Salvar anotações no navegador
- [ ] Criar metas personalizadas
- [ ] Adicionar gráficos de produtividade

## Tecnologias Usadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Estrutura do projeto

```text
my-personal-dashboard/
```

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto (https://github.com/Renato1jj/Dashboard-pessoal/tree/main/C%C3%B3digos%20).
3. Execute o arquivo index.html no navegador.
