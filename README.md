# Dashboard Pessoal

Um dashboard pessoal desenvolvido para organizar tarefas, acompanhar metas e registrar anotações diárias.

## Funcionalidades

- [x] Relógio e data em tempo real
- [x] Adicionar tarefas
- [x] Concluir tarefas
- [x] Excluir tarefas
- [x] Contador de tarefas
- [x] Salvar tarefas no LocalStorage
- [x] Salvar anotações no navegador
- [ ] Criar metas personalizadas
- [ ] Adicionar gráficos de produtividade

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Como executar

1. Clone este repositório:

   ```bash
   git clone URL_DO_SEU_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd my-personal-dashboard
   ```

3. Abra o arquivo `index.html` no navegador.
